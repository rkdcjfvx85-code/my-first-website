해결 방법 (gh CLI 설치)

1. PowerShell에서 아래 명령을 실행해요.
winget install --id GitHub.cli
2. 설치가 끝나면 터미널과 Claude Code를 다시 시작해요. 그래야 PATH에 반영돼요.
3. 아래 명령으로 GitHub 계정에 로그인해요. 브라우저 OAuth 방식이에요.
gh auth login
4. gh auth status를 실행해서 로그인됐는지 확인해요.

남은 단계: GitHub 로그인
-------------------------------
로그인은 브라우저에서 직접 승인해야 해서 제가 대신 할 수 없어요. 아래 순서로 진행해 주세요.

1. Claude Code와 터미널을 모두 껐다가 다시 켜 주세요. 새 PATH는 다시 시작해야 적용돼요.
2. 터미널에서 아래 명령을 실행해요.
gh auth login
3. 질문이 나오면 차례로 이렇게 선택해요.
   - GitHub.com
   - HTTPS
   - Authenticate Git with your GitHub credentials? → Yes
   - Login with a web browser
4. 화면에 나온 8자리 코드를 열린 브라우저에 입력하고 Authorize를 눌러요.
5. 마지막으로 gh auth status를 실행해서 Logged in to github.com account rkdcjfvx85-code가 나오면 완료예요.

로그인을 마치고 알려주시면 연결 상태를 다시 확인해 드릴게요. 😊
